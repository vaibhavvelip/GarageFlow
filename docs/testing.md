# Chapter 6 — Software Testing & QA Evaluation

## 6.1 Testing Methodology

Quality assurance for **GarageFlow** followed a structured test lifecycle:
1. Requirements Analysis & Test Planning (`qa/test-plan.md`)
2. Test Case Specification — 62 detailed test cases across 10 modules (`qa/test-cases.md`)
3. Defect Discovery, Root Cause Analysis, and Developer Fix (`qa/bug-report.md`)
4. Postman API Suite Execution (`GarageFlow.postman_collection.json` & `qa/api-testing.md`)
5. Regression Testing Matrix (`qa/regression-testing.md`)
6. Cross-Browser & Responsive Compatibility Matrix (`qa/compatibility-testing.md`)
7. Final QA Sign-Off Report (`qa/test-summary.md`)
