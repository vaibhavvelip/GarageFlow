# Chapter 3 — Technology Stack Justification

| Technology Layer | Selection | Justification & Technical Alignment |
| :--- | :--- | :--- |
| **Frontend UI** | HTML5, CSS3, Vanilla JS, Bootstrap 5 | Provides lightweight, dependency-free client performance, maximum styling flexibility, responsive layout grid, and rapid DOM manipulation. |
| **Backend API Engine** | Node.js + Express.js | Non-blocking asynchronous I/O event loop ideal for handling concurrent API traffic, lightweight middleware routing, and seamless JSON payload parsing. |
| **Database Engine** | InsForge PostgreSQL (Cloud BaaS) | Production-grade managed PostgreSQL with Row-Level Security (RLS), foreign key constraints, robust indexing, automated backups, and unified BaaS client SDK. |
| **Security & Auth** | BcryptJS + JSON Web Tokens (JWT) | Industry-standard password hashing with salt factor 10, stateless bearer token auth, and role-based route middleware protection. |
| **API Testing Suite** | Postman v10.x | Endpoint payload validation, response code verification, and collection export for academic submission. |
